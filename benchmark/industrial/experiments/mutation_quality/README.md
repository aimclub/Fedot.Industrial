# Подготовка сравнения качества мутаций

`protocol.json` — отдельная матрица из 15 сценариев, трёх вариантов и пяти зерён.
`config.py` проверяет её без чтения данных; `preflight.py` читает только TRAIN
и строит проверяемые разбиения. `__main__.py` по умолчанию показывает бюджет,
а с `--preflight` сохраняет новый отчёт. Команды полной обучающей серии в пакете нет.

Полный протокол, ограничения и критерии готовности:
[описание эксперимента](../../../../examples/release_1_0/evolution/mutation_quality_protocol.md).

```powershell
python -m benchmark.industrial.experiments.mutation_quality
python -m benchmark.industrial.experiments.mutation_quality --preflight --output-dir examples/artifacts/cloud_bundle/mutation_quality_20261030/preflight_03
```

Исходные наборы остаются локальными, в Git добавляются только код и протокол.
Отчёты находятся в исключённом из Git `cloud_bundle`. Предварительная проверка
не заменяет проверку фактического диспетчера мутаций, обучение и приёмку качества.
Ссылочные файлы прежней исследовательской процедуры должны быть доступны локально;
их отсутствие отмечается как препятствие, а не заменяется новыми параметрами.

## Технические пилоты A/B/C

`runner.py` переиспользует `evolution_parallelism.search.run_search` и управление
процессами из `supervisor`. `study.py` адаптирует существующую подготовку параметров
и прогнозных графов. Нового поискового цикла или кэша оценок нет.

```powershell
python -m benchmark.industrial.experiments.mutation_quality --technical
python -m benchmark.industrial.experiments.mutation_quality --technical --execute --output-dir examples/artifacts/cloud_bundle/mutation_quality_technical_20261030/pilot_01
```

Первая команда только показывает план. Вторая выполняет строго девять пилотов:
ECG200, NaturalGasPricesSentiment, Airline × A/B/C, seed 42. Одно поколение после
начальной популяции, 150 секунд на подготовку и поиск, прежние 90 секунд на
кандидата, внешний ограничитель 420 секунд на процесс с итоговым обучением.
Пилот останавливается после первого отказа. Каталог результата должен быть новым.
Произвольные наборы, бюджеты и полная матрица из 225 запусков через этот CLI
не запускаются. `protocol.json.training_enabled=false` относится к полной серии;
технический режим требует отдельного явного `--execute`.

У A структурная перезапись отсутствует в фактическом списке агента, разрешённых
видах планов и трассах. B/C сохраняют прежние действия. Веса нулевой во всех
этапах перезаписи больше не приводят к автоматическому добавлению действия.
Остальные действия и пользовательская конфигурация не изменяются.

Пилот обучает победителя на первом внутреннем TRAIN-разбиении и проверяет
конечность прогнозов на соответствующей внутренней проверке. Внешний контроль
и официальный TEST не оцениваются. Качество по этим пилотам не сравнивается.
Результаты содержат `arm_contract.json`, `mutations.jsonl`,
`technical_verification.json`, встроенную диагностику Dask и общий `jobs.json`.
Между вариантами одного сценария сверяются источники, разбиения, начальные
параметры и настройки Torch. Исходники заморожены на всю серию.

## Доставка данных и заморозка полного плана

```powershell
python -m benchmark.industrial.experiments.mutation_quality --prepare-data --output-dir examples/artifacts/cloud_bundle/mutation_quality_data_20261030
python -m benchmark.industrial.experiments.mutation_quality --freeze --output-dir examples/artifacts/cloud_bundle/mutation_quality_freeze_20261030/frozen_01
python -m benchmark.industrial.experiments.mutation_quality --verify-freeze --output-dir examples/artifacts/cloud_bundle/mutation_quality_freeze_20261030/frozen_01 --expected-seal eccbefbd7e1cc2b6d0d74188369e13c4145c40c9c8a408606b74333c76930d97
```

Заморозка требует нового каталога и не запускает обучение. Проверка требует
неизменного состава файлов, хешей, массивов и актуальных исходников. SHA-256
`seal.json` — внешняя опорная идентичность этого конкретного пакета; новое создание
пакета может иметь другой SHA из-за метаданных архивов и времени создания.
Изменение исходников после заморозки требует явного нового пакета, не правки старого.

`external_sources.json` закрепляет URL и контрольные суммы. M4 скачивается только
из официального Train. Monash передаёт неразделённый архив: преобразователь
отбрасывает 168 последних текстовых токенов каждого ряда до числового разбора.
Архив — только источник доставки; в замороженные входы попадает производный TRAIN,
не будущий хвост. Внутренний горизонт моделей остаётся 12.

`lock.json` содержит разбиения, политики, настройки моделей, исходные пороги,
порядок и бюджеты 225 работ. `inputs/` хранит числовые массивы всех внутренних
разбиений, итогового обучения и внешнего контроля внутри TRAIN; `sources.zip` —
снимок кода. `seal.json` связывает файлы контрольными суммами. Загрузка NPZ
выполняется с `allow_pickle=false`, архив кода проверяется без исполнения.

Полная серия остаётся отключённой. `matrix_ready` означает готовность входов,
а успешная заморозка — целостность плана, не результаты обучения всех 15 сценариев.
Нужны отдельное разрешение на бюджет и проверка будущего полного исполнителя.
Подробности: [отчёт заморозки](../../../../examples/release_1_0/evolution/mutation_quality_freeze_20261030.md).
