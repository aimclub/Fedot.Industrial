# Подготовка сравнения качества мутаций

`protocol.json` — отдельная матрица из 15 сценариев, трёх вариантов и пяти зерён.
`config.py` проверяет её без чтения данных; `preflight.py` читает только TRAIN
и строит проверяемые разбиения. `__main__.py` по умолчанию показывает бюджет,
а с `--preflight` сохраняет новый отчёт. Команды обучения в пакете пока нет.

Полный протокол, ограничения и критерии готовности:
[описание эксперимента](../../../../examples/release_1_0/evolution/mutation_quality_protocol.md).

```powershell
python -m benchmark.industrial.experiments.mutation_quality
python -m benchmark.industrial.experiments.mutation_quality --preflight --output-dir examples/artifacts/cloud_bundle/mutation_quality_20261030/preflight_03
```

Исходные наборы остаются локальными, в Git добавляются только код и протокол.
Отчёты находятся в исключённом из Git `cloud_bundle`. Предварительная проверка
не заменяет проверку фактического диспетчера мутаций, обучение и приёмку качества.
Ссылочные файлы прежней исследовательской процедуры должны быть доступны локально;
их отсутствие отмечается как препятствие, а не заменяется новыми параметрами.
