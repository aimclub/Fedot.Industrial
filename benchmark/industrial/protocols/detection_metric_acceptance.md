# Приёмка метрик детекции

Проверка DATA-06 в PR #356. Новые модели не обучались. Проверены закреплённые
выпуски TSB-AD-U и TSB-AD-M и один поток NAB. Проверка метрик не является
полным прогоном бенчмарков или новым рейтингом моделей.

## TSB-AD: данные и VUS-PR

Состав обоих архивов совпал с авторскими перечнями. Списки настройки и
оценки не пересекаются; малый список `Eva` включён в полную оценочную часть.

| Выпуск | Всего рядов | Настройка | Оценка `Eva` | Полная оценочная часть |
| --- | ---: | ---: | ---: | ---: |
| TSB-AD-U | 870 | 48 | 350 | 822 |
| TSB-AD-M | 200 | 20 | 180 | 180 |

Для численной сверки взят по одному примеру из авторской папки каждого
выпуска; оба примера входят в `Eva`. Балл в каждый момент — среднее
по каналам от абсолютных разностей с предыдущим наблюдением. Масштаб
канала — средняя абсолютная разность внутри TRAIN; для постоянного
канала используется множитель 1. Больший балл означает большую
аномальность. VUS-PR считается на хвосте после TRAIN; контрольная
разметка не участвует в расчёте баллов и не подбирает порог.

| Пример | Каналы | TRAIN / TEST | Аномальные точки TEST | VUS-PR Industrial / `opt_mem` |
| --- | ---: | ---: | ---: | ---: |
| U: `001_NAB_id_1_Facility_tr_1007_1st_2014` | 1 | 1007 / 3024 | 343 | 0,209690756702826 / 0,209690756702826 |
| M: `057_SMD_id_1_Facility_tr_4529_1st_4629` | 38 | 4529 / 19 165 | 542 | 0,172110206198760 / 0,172110206198760 |

Industrial вызывает авторский `opt`; отдельно проверен результат
авторского `RangeAUC_volume_opt_mem`. Обе реализации взяты из одной
[закреплённой ревизии TSB-AD](https://github.com/TheDatumOrg/TSB-AD/tree/303dffbfc11612995b17b06633f8c9d0ea0e38e5).
Окно VUS — 100 отсчётов, число уровней порога — 250, численный допуск —
`1e-12`. Файл вычислителя проверяется по SHA-256.

VUS-PR оценивает непрерывный балл, а не маску тревог. Точечная средняя
точность (AP) считается отдельно. Ряд без аномалий не получает численный
VUS-PR (`not_available`); нечисловые баллы отклоняются. `Point adjustment`
не применяется. TSB-UAD не смешивается с этими выпусками. Yahoo S5 и
AIOps в проверку не входят: доступ к точным выпускам и условия
использования не подтверждены.

## NAB: задержка и ложные тревоги

Взяли [поток температуры и разметку из NAB](https://github.com/numenta/NAB/tree/ea702d75cc2258d9d7dd35ca8e5e2539d71f3140).
Точка потока — фактическое наблюдение; точка разметки — отметка события
авторов; окно тревоги — отдельный опубликованный интервал, включающий
обе границы. Правильное обнаружение — первая тревога внутри окна.
Следующие тревоги в этом окне считаются повторами, тревоги за пределами
всех окон — ложными. Задержка измеряется от **начала окна**, а не от
точки разметки. Это не сводный NAB Score.

Балл — абсолютное изменение между соседними доступными наблюдениями.
Порог `2,1937688772` получен как 99-й процентиль первых 1090
наблюдений (15% потока), без разметки. После этой границы порог не менялся.

| Показатель | Результат |
| --- | --- |
| Проверено после TRAIN | 6177 наблюдений за 6766 календарных часов |
| Часы без наблюдений | 589; не заполнены, в этих часах не создавались тревоги |
| События | 2 обнаружены, 0 пропущены |
| Задержка первых тревог | 157 и 41 час от начала соответствующих окон |
| Тревоги | 62 всего: 2 первых в окнах, 7 повторов, 53 ложных |
| Ложные тревоги за час | 0,0078332841 по всему календарному времени после TRAIN |

Все значения совпали с независимым подсчётом по временным отметкам.
Пропуски входят в длительность наблюдения, но не заменяются измерениями.
Это важно: использование номера строки вместо времени изменило бы
задержки и частоту ложных тревог.

## Как повторить

Имена, источники и SHA-256 закреплены в
[манифесте DATA-06](../examples/detection_metric_acceptance_sources.json).
Положите авторские ZIP TSB-AD-U/M в `DATA_ROOT`, не распаковывая их.
Положите туда же перечисленные CSV из
[авторских списков разбиений](https://github.com/TheDatumOrg/TSB-AD/tree/303dffbfc11612995b17b06633f8c9d0ea0e38e5/Datasets/File_List)
и три файла NAB под именами из манифеста. Лицензия кода TSB-AD
не распространяется автоматически на исходные наборы; сверяйтесь
с [перечнем лицензий авторов](https://thedatumorg.github.io/TSB-AD/).
Данные в Git не входят.

```console
python -m pip install --no-deps "TSB_AD @ git+https://github.com/TheDatumOrg/TSB-AD.git@303dffbfc11612995b17b06633f8c9d0ea0e38e5"
python -m benchmark.industrial.examples.verify_detection_metrics DATA_ROOT
python -m benchmark.industrial.examples.verify_detection_metrics DATA_ROOT --suite nab
```

Установка вычислителя нужна только для сверки TSB-AD. Команда сверки
не обращается к сети и не создаёт файлов; результат печатается в JSON.
