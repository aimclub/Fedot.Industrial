# DATA-10: Отчёт по сохранённым прогонам

[HTML для просмотра без сети](../examples/saved_protocol_report/report/index.html) ·
[CSV для анализа](../examples/saved_protocol_report/report/metrics.csv) ·
[Источники и контрольные суммы](../examples/saved_protocol_report/manifest.json)

Отчёт собран из результатов уже выполненных прогонов. Он не пересчитывает
прогнозы, не обучает модели и не сравнивает значения из разных протоколов.

| Группа | Метрика | План | Прошли | Неполные | Сбой |
| --- | --- | ---: | ---: | ---: | ---: |
| Классификация B/D, 5 наборов | Сбалансированная точность | 50 | 48 | 1 | 1 |
| Регрессия B/D, 5 наборов | RMSE | 50 | 25 | 22 | 3 |
| Прогнозирование B/D, 5 рядов | RMSE | 50 | 50 | 0 | 0 |
| TIME, 1 ряд × 5 окон × 2 метода | MAE | 10 | 10 | 0 | 0 |
| Детекция NAB, 1 поток | Ложных тревог за час | 1 | 1 | 0 | 0 |

### Как читать числа

- **B/D.** Контрольная часть TRAIN, официальная часть TEST не использовалась.
  Ревизия Industrial — `cc65b060`; состав данных и протокол закреплены
  контрольной суммой `frozen_04`. Пять фиксированных начальных значений
  генератора случайных чисел на вариант и набор. Лимиты: 600 с на поиск,
  90 с на кандидата, 1200 с на процесс, четыре исполнителя Dask.
  Одновременных поисков не было. Прогноз проверялся на горизонте 12;
  это не полный прогон M4 или Monash.
- **Сопоставление B/D.** HTML показывает по каждому набору пересечение
  успешных поисков при одном и том же начальном значении. Получилось
  23/25 пар в классификации, 10/25 в регрессии и 25/25 в прогнозировании.
  Начальные значения дают повторы на одном разбиении, а не независимые
  наборы. Оценки неполных поисков видны, но в пары не входят.
  Обычная точность из архивных таблиц не сопоставляется
  со сбалансированной. Общий рейтинг не строится.
- **[TIME](time_transfer_acceptance.md).** Средняя MAE Chronos-Bolt-Tiny
  составила 6,42093 против 6,96667 у повтора последнего значения. Это
  пять окон по 12 месяцев одного ряда; нет подтверждения, что ряд
  отсутствовал в данных предобучения.
- **[NAB](detection_metric_acceptance.md).** На одном потоке с порогом,
  рассчитанным только на первых 1090 наблюдениях, получено
  53 ложные тревоги за 6766 часов (0,0078332841 в час).
  Это не сводный NAB Score и не рейтинг детекторов.

### Повторная сборка

Из корня рабочей копии (Python 3.10 или новее):

```console
python -m benchmark.industrial.examples.report_saved_runs ./data10-report
```

Команда читает только манифест и небольшие сохранённые сводки рядом с ним.
Она проверяет SHA-256 и разбирает те же байты, по которым рассчитана
контрольная сумма. Для TIME отдельно сверяется выпуск данных. Команда
пишет `index.html` и `metrics.csv` в указанную папку и отклоняет пути,
при которых отчёт перезаписал бы входной файл. Изменённая сводка
вызывает ошибку; отсутствующая оставляет ожидаемые строки со статусом
`unavailable`. Одинаковая запись учитывается один раз. Различающиеся записи
для одной ячейки и противоречащие друг другу причины остановки одной
попытки B/D отклоняются. Ни ROAST, ни модельные
зависимости, ни интернет для сборки не требуются.

Поле `artifact` указывает на папку попытки в исходном комплекте B/D
или на раздел в сохранённой сводке. В Git не вошли исходные ряды,
индивидуальные прогнозы, веса и журнал всех кандидатов. Полную историю
B/D следует открывать в исходном комплекте `industrial_bd_20261111`.
Для наборов из статей и старых таблиц этот отчёт не создаёт замену
сохранённым результатам прогона. Перенос исполнителя и хранилища в ROAST
относится к #304 и #308.
