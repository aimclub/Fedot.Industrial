# Прогноз без дообучения на пяти окнах TIME

Проверка DATA-08 в PR #356. Сравниваются [Chronos-Bolt-Tiny](https://huggingface.co/amazon/chronos-bolt-tiny/tree/a0e552de83495b5c28c14c71c374f3e33280b340)
с неизменными весами и повтор последнего наблюдения. Использован один
[месячный ряд производства бумаги и целлюлозы](https://huggingface.co/datasets/Real-TSF/TIME-ProcessedCSV/blob/683bb21b470f5a26586e1ab2295f0a2a1529ef0f/Commodity_Production/M/IndexofPaperandPulpProductionforUnitedStates_m.csv)
из `TIME-ProcessedCSV`, тот же, что в малом примере Industrial.

## Разбиение и входы

Из последних 60 точек получены пять неперекрывающихся окон по 12 месяцев
согласно [настройкам TIME](https://github.com/zqiao11/TIME/blob/e8bb342f7625deda36742df8b39f91cefb82434b/src/timebench/config/datasets.yaml).
На каждом шаге обеим моделям доступна история до указанной даты
включительно. В следующих окнах история расширяется только за счёт
уже наступивших наблюдений. В Chronos передаются значения одного ряда
и длина горизонта, без будущих значений и дополнительных признаков.
В качестве точечного прогноза используется медиана (квантиль `0.5`).
Веса, настройки и правило прогноза не подбирались по контрольным данным.

## Результат

| Последнее наблюдение | История, точек | MAE Chronos | MAE повтора | Разница MAE |
| --- | ---: | ---: | ---: | ---: |
| 1952-01 | 61 | 5,42294 | 5,50000 | −0,07706 |
| 1953-01 | 73 | 6,48728 | 6,08333 | +0,40395 |
| 1954-01 | 85 | 4,07830 | 6,91667 | −2,83836 |
| 1955-01 | 97 | 10,39427 | 11,00000 | −0,60573 |
| 1956-01 | 109 | 5,72187 | 5,33333 | +0,38853 |
| **Среднее** | | **6,42093** | **6,96667** | **−0,54573** |

MAE Chronos ниже на **7,83%** в среднем; модель выиграла на трёх окнах
из пяти. Выигрыш определило окно 1954-01: без него средняя MAE Chronos
была бы на 0,02742 выше, чем у повтора.
Два запуска в отдельных процессах дали одинаковые значения MAE по всем
окнам. В одном из запусков загрузка модели заняла 0,165 с, медианное
время прогноза на окно — 8,74 мс. Это замеры на одной машине, а не
сравнительный тест производительности.

Предобучение могло включать этот исторический ряд или его копию: публичная
[карточка Chronos-Bolt-Tiny](https://huggingface.co/amazon/chronos-bolt-tiny/blob/a0e552de83495b5c28c14c71c374f3e33280b340/README.md)
не позволяет исключить совпадение точного ряда и периода. В результате
поэтому указан `overlap: "unknown"`. Это проверка без дообучения на
одном ряде, а не доказательство переноса на незнакомые данные или результат
по всему TIME. Time-IMM и LargeST в эту проверку не включены.

## Как повторить

Нужен установленный проект с PyTorch. Проверка выполнена на Python 3.10,
PyTorch `2.5.1+cpu`, в `float32` и с одним потоком Torch. Пакеты
прогнозирования можно установить в отдельное окружение:

```console
python -m pip install chronos-forecasting==1.5.3 transformers==4.49.0 accelerate==1.3.0 huggingface-hub==0.28.1 tokenizers==0.21.0 safetensors==0.5.3 regex==2024.11.6
python -m benchmark.industrial.examples.verify_time_transfer DATA_ROOT
```

До запуска положите исходный CSV в `DATA_ROOT/time/paper_pulp.csv`, а
`config.json` и `model.safetensors` из закреплённой ревизии Chronos в
`DATA_ROOT/model/chronos-bolt-tiny/`. SHA-256 ряда перечислена в
[каталоге TIME](../examples/time_transfer_smoke.json); хеши весов и
конфигурации, даты и версии пакетов — в
[манифесте сравнения](../examples/time_transfer_acceptance.json).
Команда работает с локальными файлами, не запускает обучение и выводит
JSON. Исходные данные и веса не добавлены в Git.
