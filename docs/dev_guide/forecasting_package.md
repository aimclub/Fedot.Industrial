## Граница переноса

| Семейство | В самостоятельном пакете | В Industrial |
| --- | --- | --- |
| Наивный, сезонный наивный, среднее, дрейф, скользящее среднее, линейный тренд | Модели NumPy и временные контракты | Загрузка данных, запуск и отчёты бенчмарка |
| Лаговый и низкоранговый Ridge | Преобразования, решение и прогноз, включая прежнюю тензорную реализацию | Преобразование входов FEDOT и регистрация операций |
| SSA/MSSA, HAVOK | Траекторные преобразования, линейная и MLP-модели переходов | Преобразование входов FEDOT |
| Гибридный ансамбль | Калибровка весов, лаговая, низкоранговая и HAVOK-ветви | Подключение прежней ветви OKHS через адаптер |
| PatchTST, TST, TCN, DeepAR, N-BEATS | Тензорная сеть TCN и общие правила нейросетевых настроек | Обучение через `BaseNeuralModel` и подготовка данных FEDOT; тензорные сети PatchTST, TST, DeepAR и N-BEATS |
| TopologicalAR, OKHS-FDMD, GLM и встроенные модели FEDOT | Общая настройка через переданную фабрику моделей | Сами модели и их зависимости |

Перенос не меняет алгоритмы, параметры по умолчанию, сетки настройки или
каталог операций. Точки входа Industrial сохраняются. Модели, которые ещё
зависят от подготовки данных FEDOT, не объявляются самостоятельными.
В TCN остаточное сложение больше не меняет тензор на месте: прежде это
срывало обратный проход при нулевом dropout. Формула прямого прохода та же.

## Временная сетка и метрики

Совместимый адаптер FEDOT сохраняет обработку календарной частоты и прежние
коды ошибок. Пакет принимает уже разрешённые координаты и проверяет их
порядок и отсутствие пересечения с историей. Нельзя передать будущие
значения признака, который известен только в прошлом.

Единый расчёт OWA сохраняет два прежних варианта оценки отдельных шагов:
при настройке делители вычисляются для всего горизонта, в отчётах для
каждого шага. Итоговый OWA в обоих случаях использует делители для всего
горизонта. Среднее значений из отчёта по шагам не заменяет итоговый OWA.

## Проверка совместимости

На CPU сопоставлены шесть сценариев до переноса (`ee7a3801`) и после:
лаговый Ridge, низкоранговый Ridge, MSSA с линейным и MLP-блоками, HAVOK и
гибридный ансамбль. История: 96 значений ряда
`0.11 * t + sin(t / 4)`, горизонт: 3. Во всех случаях максимальное
абсолютное отклонение прогноза равно нулю. MAE и поля диагностики также
совпали. Численные значения для двух вариантов Ridge закреплены в
`tests/unit/forecasting/test_neural_models.py`. Это проверка переноса,
не сравнение качества моделей на бенчмарке.

Собраны исходные архивы и wheel всех трёх пакетов. Базовая установка
`industrial-forecasting` работает с NumPy в отдельном окружении без FEDOT
и PyTorch. Установка с `neural` проверена отдельно, также без FEDOT.
При установке всех трёх wheel сценарий `tools/runtime_smoke.py` проверяет
прогноз через FEDOT с заранее известным горизонтом и индексом.

```bash
python -m pytest tests/unit/forecasting tests/unit/integration/fedot/test_temporal_forecasting_runtime.py -q
python -I examples/forecasting_package.py --standalone
python -I examples/forecasting_package.py --standalone --neural
```

Две последние команды предназначены для разных окружений; порядок установки
приведён в [README пакета](../../packages/industrial-forecasting/README.md).
Воспроизводимость B/D по-прежнему проверяется по фактически импортированным
исходникам. Новая версия включает в снимок `industrial_forecasting`;
исторические серии и их зафиксированные исходники не меняются.
