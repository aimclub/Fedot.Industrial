# PLT-01: результаты проверки

Дата: 18 сентября 2026 года. Обновлено 21 сентября 2026 года.
Ветка: `industrial_release_1.0`.
Основа: `origin/main`, `cb76d9af80d74209478172cce3bb1a4bb5842e89`.

## Выполненные изменения

- Метаданные установки сведены в `pyproject.toml`; `setup.py` использует их
  без второго набора значений. `requirements.txt` проверяется как точный
  автоматический экспорт основных зависимостей.
- FEDOT закреплён на прежнем снимке из lock-файла:
  `42f3ba490407a1106e898e94232f2afd0a78f73f`.
  Целевая ветка FEDOT 1.0 обозначена отдельно, как будущий этап интеграции.
- Устранён конфликт DaskML 2025 со scikit-learn, требуемым Giotto-TDA.
  Исправлена воспроизведённая ошибка импорта старого datasets с новым PyArrow.
- Дополнительные средства тестирования и Jupyter описаны отдельными группами.
  Несовместимые исследовательские зависимости не устанавливаются по умолчанию.
  Временное ограничение транзитивного typing сопровождается проверкой
  использования стандартного модуля Python.
- Добавлены проверки структуры матрицы, установленных версий и происхождения
  FEDOT; проверки состава wheel/sdist и короткие проверки установленного API.
- Процедуры CI используют точные версии из `uv.lock`. Сборка общая для
  проверок и публикации; установка wheel проверяется отдельно от исходников.
- Удалён устаревший значок GitLab-зеркала; обновлены инструкции установки.
  Это само по себе не означает закрытие связанных GitHub issues.

## Локальное окружение

Созданы новые окружения в игнорируемом каталоге `.local`; существующие
`venv_3.9_new`, Miniconda и другие рабочие окружения не изменялись.

| Окружение | Назначение |
| --- | --- |
| `.local/platform-tools`, Python 3.10 | Проверки настроек, сборка и разрешение зависимостей |
| `.local/install-310`, Python 3.10.0 | Установка зависимостей и итогового wheel на Windows |
| `.local/install-311`, Python 3.11.5 | То же на Python 3.11 и целевые регрессионные тесты |

В обоих окружениях использован PyTorch 2.5.1+cpu и torchvision 0.20.1+cpu.
Версии зависимостей установлены из замороженного экспорта `uv.lock`.
Номера Python отражают доступные локальные интерпретаторы, а не рекомендацию
использовать старые исправляющие выпуски.

## Ограничения

- Полный набор модульных тестов выполнен локально на Windows. Единственное
  падение было вызвано запретом песочницы на создание именованного канала
  Windows в `joblib`; тот же
  тест успешно пройден вне песочницы. Linux-установка и повторный полный прогон
  должны быть подтверждены GitHub Actions перед вливанием PLT-01.
- На локальной машине нет Python 3.12. Проверены правила отказа и тестовые
  случаи; реальный отказ установки wheel проверит отдельная задача CI.
- Python 3.12 не объявлен поддерживаемым; #125 не закрывается.
- CUDA, распределённое обучение, Jupyter-сценарии и исследовательские Deep
  OKHS-запуски не проверялись в этом этапе.
- Полный импорт API на первых запусках занимал около трёх минут.
  Проверки завершились; ускорение загрузки предметных модулей относится
  к дальнейшей декомпозиции, а не считается выполненным здесь.
- `distribution_check --pypi` ожидаемо отказывает из-за прямой Git-зависимости
  FEDOT. Публиковать эту подготовительную ветку в PyPI нельзя; нужна
  совместимая опубликованная версия FEDOT и повторная проверка установки.
- Исследовательские данные и исходные эксперименты не менялись. Цикл FED-01–03
  подготовлен в Pull Request FEDOT #1462 и проверен отдельно; BIN-01 в ROAST
  в PLT-01 не выполнялся.

Подробные JSON-отчёты, журналы и дистрибутивы находятся локально в `.local`:
`environment-310.json`, `environment-311.json`, `smoke-310.json`,
`smoke-311.json`, `regression-tests.log`, `unit-collection.log`,
`plt01-dist/`. Они не включаются в git и дистрибутив.
