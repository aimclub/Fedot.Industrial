## Доступность

Статус нового архива: **только локально, не опубликован**.
`external_archive_url` в манифесте равен `null`. Прежняя публичная ссылка Яндекс
Диска из общего каталога не объявляется источником новых данных EVO/NN:
наличие там этих файлов не проверено. Файлы нельзя считать скачиваемыми, пока
владелец не опубликует архив и не запишет проверенную ссылку в манифест.

Для публикации используйте отдельное хранилище данных через DVC с настроенным
S3-совместимым хранилищем либо ручную выгрузку каталога. В Git должны попадать
манифесты и указатели `.dvc`, но не сами отчёты. Настройка хранилища и ключи доступа
не добавляются в код фреймворка. `dvc add` создаёт указатель на данные, а S3-remote
настраивается отдельно; секреты хранятся в переменных окружения или
`.dvc/config.local`. См. [dvc add](https://doc.dvc.org/command-reference/add) и
[DVC с S3](https://doc.dvc.org/user-guide/data-management/remote-storage/amazon-s3).
Ни создание внешнего хранилища, ни публикация, ни настройка учётных данных здесь
не выполнялись.

## Правила хранения

- В `docs/dev_guide` остаются инструкции и краткие выводы, не полные таблицы опыта.
- Обычные тесты не зависят от локальных полных архивов и закрытых данных.
- В тестовых данных допустимы маленькие проверяемые конфигурации, не результаты
  нового обучения. При изменении такой выборки должны сохраняться проверяемые
  идентификаторы и ограничения.
- Не коммитьте содержимое `cloud_bundle/`, контрольные точки или новые файлы
  профилирования. Старые несвязанные локальные отчёты владельца не переносились.
- Данные опыта не подтверждают приёмку новой версии автоматически. EVO-04 остаётся
  отклонённым; новый планировщик мутаций выключен по умолчанию.
