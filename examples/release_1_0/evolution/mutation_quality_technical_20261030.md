# Подключение A/B/C и технические пилоты

## Что проверяли

Общий исполнитель `evolution_parallelism.search.run_search` подключён к
`mutation_quality`. A исключает структурную перезапись; B использует расширенный
каталог с постоянными весами; C — тот же каталог с поэтапными весами.
Начальные модели, их параметры, сетки, ограничения графов и доля семейств `0.5`
сохранены. OKHS-FDMD и пороги EVO-04 не изменялись.

`configure_actions` больше не добавляет перезапись, если её вес нулевой во всех
этапах политики. Ранее переданное одноимённое действие также исключается;
параметры вызывающей стороны не меняются. Политики B/C с положительными весами
сохраняют действие. Этот контракт проверяется до запуска поиска и по его трассам.

## Границы запусков

Три источника: ECG200, NaturalGasPricesSentiment и Airline. Все данные — TRAIN.
По одному поколению после начальной популяции, seed 42, по три варианта:
всего девять последовательных запусков. На поиск с подготовкой выделено не более
150 секунд, на кандидата — прежние 90 секунд. Внешний ограничитель процесса —
420 секунд, включая диагностику и проверочное итоговое обучение.

Режим Dask: один собственный кластер на поиск, четыре процесса по одному рабочему
потоку Dask. OMP/MKL/OpenBLAS/NumExpr=1 только в дочернем окружении, как раньше.
В каждом процессе Torch до и после: `threads=1`, `interop_threads=16`,
`deterministic=false`. Настройки Torch не менялись программно.

Поиск оценивает кандидатов на трёх внутренних разбиениях TRAIN. Выбранная модель
дополнительно обучается на первом внутреннем разбиении и возвращает конечные
прогнозы. Ни внешний TRAIN-контроль, ни официальный TEST не оцениваются.
Это проверка работоспособности, **не сравнение итогового качества**.

## Результат

Все девять запусков завершились с кодом 0 и одним поколением. Всего 143 успешные
оценки, ошибок обучения нет. Счётчик перезаписей ниже — принятые действия
`rewrite_subgraph_mutation`, а не все рассмотренные структурные предложения.

| Источник | Вариант | Успешные оценки | Принятые перезаписи |
| --- | --- | --- | --- |
| ECG200 | A | 16 | 0 |
| ECG200 | B | 16 | 2 |
| ECG200 | C | 17 | 9 |
| NaturalGas | A | 16 | 0 |
| NaturalGas | B | 16 | 3 |
| NaturalGas | C | 16 | 8 |
| Airline | A | 13 | 0 |
| Airline | B | 17 | 7 |
| Airline | C | 16 | 9 |

У A перезаписи отсутствуют сразу на трёх уровнях: в действиях агента, в
`enabled_kinds` планировщика и в семействах рассмотренных правок. Обычные
добавление, замена и удаление сохранены; A не означает запрет любых изменений
структуры. B/C действительно использовали `rewrite_chain`; дополнительно
наблюдались `fork_feature_branch`, `prune_feature_branch` и прогнозное ветвление.

13 оценок у Airline/A не означают ошибки обучения: диагностика содержит
28 отказов `duplicate_graph`, а число ошибок оценки равно нулю. Это полезное
наблюдение о повторяемости кандидатов, но не доказательство преимущества B/C.
Короткий поиск не обязан пройти все временные этапы C; переключения этапов
отдельно проверены тестами, а не объявлены пройденными на этих данных.

## Проверки и артефакты

- 70 целевых тестов прошли, включая реальную мутацию без разрешённого `fit`,
  прежние проверки поэтапного поиска, границы TRAIN и предварительный режим CLI.
- Между вариантами каждого источника совпали идентичности данных, разбиений
  и начальных параметров. Итоговая модель соответствует ранее оценённой конфигурации.
- JSONL и итоговые JSON совпали во всех девяти запусках. Все клиенты закрыты.
  Проверены 45 наблюдавшихся идентичностей PID плюс время создания: живых нет.
- 1139 исходных файлов совпали с замороженными хешами после всей серии.
- Сохранены девять встроенных отчётов Dask; профили собраны без структурированных
  ошибок экспорта. При этом в пяти журналах есть `CommClosedError` при закрытии,
  в одном — предупреждение о задержке цикла событий. Они не скрыты и не означают,
  что накладные расходы Dask полностью устранены.

для каждого источника. Они восстановлены после серии без обучения, сверены с
идентичностями источников всех девяти запусков и проверены обратным чтением NPZ.
Копирование или перенос исходных пользовательских датасетов не выполнялись.

Среда — `.local/evo04-cpu-20261019` и локально исправленный FEDOT из
`.local/worktrees/fedot-evo04-ci-smoke`. Чистая опубликованная зависимость и GitHub CI
заново не проверены. Прежние незакоммиченные зависимости исследовательского
исполнителя остаются отдельной задачей интеграции; локальная работоспособность
не равна готовности всего набора исходников к вливанию в main.
